Planned Enhancements

Software Engineering and Design

Completed

This enhancement focuses primarily on improving the reliability and organization for the TrackItPro app. Event notifications currently use the exact alarms without checking whether the required premissions have been granted. A premission check will be added prior to scheduling an exact alarm. If the permission is unavailable the application will direct the user to the settings menu to enable this premission instead of attempting to schedule the alarm which caused the application to crash.

The application structure will be improved by seperating the operations from the activity classes. Database operation currently occurs directly inside the activities such as the EventActivity, AddEventActivitiy, and EventDetailActivity. These operations will be moved into a seperate layer. This change will seperate the user interface from the data access logic thus making the application easier to maintian, test, and troubleshoot.

In completing this enhancement there were two seperate reposiotries added to the code EventRepository & UserRepository. The event repository handles all the database helper with how it interacts with the events and the userRepository handles the database helper in how it reacts with the user records. This migration into repository classes gives a seperation of the the user interface which is handled in the other classes and helps the methods from being to overloaded in handling multiple items reducing the complexity and improving the maintainability. Another improvement was removing the sms alerting that wasnt being used and hardened the code to be more devensive for all android version. This checks the permissions prior to scheduling exact alarm, and the userId is now being passed all the way through to the notification to avoid a crash if the user clicks the alert it now takes them to their event instead of crashing.

Algorithms and Data Structure

Completed

The algorithms and data structure foucuses primarily on imporoving how events are orgainized and processed. Events currently appear based on the order in which they are in the database rather than their scheduled date and time. Event retrieval will be changed so upcoming events are sorted chronologically, placing the event with the earliest scheduled time first.

Conflict detection will also be integrated so when an event is cretaed or edited. The start and end time will be compared with existing events for the user. If the range for that event overlaps another existing event the application will show an alert to the user prior to saving the event. This enchancement adds sorting and time comparison logic to improve the schedule functionality.

Completing this enhancement the event organization and processing was improved. Events are now sorted chronologically instead of the order in which they were created. Now they will show in the order that they will notify the user. Event conflict detection was also added so that newly created events will be compared with events the user had created prior. If there is a conflict the event will not be saved and the user will be notified. The logic for insertion of events was also enhanced so that it will just be inserted into the list in the list instead of it having to reload everytime. These enhancements provide sorting, searching, comparision logic, and algorithm desing. It also has an efficency part to it by using the simplest method given the data set to reduce complexity and error handling of the code to deal with complexity vs efficency coding.

Database

Planned

The database enhancement will focus on improving the security, data organization, and database management. The current SQLite Database stores account passwords as plain text. The password storage will be updated to use secure password hashing. Authentication will compare the processed password hash instead of storing and comparing the original password.

The SQLiteOpenHelper implemetation will also be replaced with Android Room. Separate entities will be created for users, events, and event categories. Relationships will connect the events to their assocaited user and categories. The event date and time field will also be indexed to support more efficient sorting and retrieval of upcoming events. These changes will increase the database security, organization, and data integrity.
